## 特性

- **完全离线**：图标、天赋树底图、前后对比截图等 858 张图片全部内联进单个 HTML，断网可用。
- **全中文**：职业、天赋、法术、改动说明均按《魔兽世界》官方译名（参照 Wowhead 中文）汉化。
- **干净**：不含任何广告、统计或追踪脚本（`googletagmanager` / `adsbygoogle` / `dataLayer` 计数均为 0）。
- **离线路由**：站内跳转要么在页内完成，要么交给系统浏览器打开上游页面，不会掉进文件系统根目录。
